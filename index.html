Utvalgt arbeid og bidrag

AI Event Assistant – PEERS AS (bacheloroppgave)

En AI-assistent der brukeren beskriver et event i naturlig språk, og assistenten fyller ut event-skjemaet automatisk i sanntid. Bygget som bacheloroppgave for PEERS AS, integrert i deres eksisterende Next.js-kodebase.

  • Backend API-route som strømmer svar ord for ord via Server-Sent Events, med todelt output: samtaletekst og JSON-blokk med feltoppdateringer
  • Sikkerhet og robusthet: rate limiting (20 forespørsler/time per bruker), input-sanitering og allowlist over hvilke skjemafelt AI-en kan endre
  • Håndterer relative datoer («neste fredag») ved å gi dato og tidssone i systemprompten
  • Frontend-chat med streaming via ReadableStream, «felt oppdatert»-bekreftelser, forslagschips og auto-resizing tekstfelt
  • Aktiverte Turbopack og kuttet kompileringstid ved hot reload fra 7–8 minutter til 4–5 sekunder (~97 % reduksjon)
  • Løste blant annet en React Context-scope-bug der AI-handlinger ble stille ignorert, og bufring av skilletegn i SSE-strømmen
Next.js React TypeScript Anthropic Claude API SSE Prisma Turbopack

Rolle: Gruppeleder og fullstack-utvikler i team på fire. Scrum med to-ukers sprinter, Slack-standups og backlog i Notion.

Kode er hos oppdragsgiver (ikke offentlig tilgjengelig).
